## Modifications made here

- The tile source, glyphs and sprite were repointed at OpenFreeMap
  (<https://openfreemap.org>), which serves the same OpenMapTiles schema without
  an API key. The sprite was dropped: no layer in this style uses an icon.
- `basic-dark.json` rewrites the colours of every drawing layer for a dark
  ground. No layer, filter, zoom rule or draw order was touched.

Both files are generated by `web/scripts/build-map-styles.mjs`, which carries the
palette and fails loudly if the upstream style drifts away from it.
